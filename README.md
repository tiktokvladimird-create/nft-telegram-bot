# NFT Telegram Mini App — MVP

Стартовый проект Telegram-бота и Mini App с NFT-призами, без CS-скинов.

## Уже есть
- Telegram-бот на aiogram 3 с кнопкой открытия Mini App.
- Mini App на FastAPI.
- Бесплатная ежедневная попытка розыгрыша NFT.
- Публично показанные шансы призов.
- SQLite для хранения пользователей и результатов.

Призы и изображения демонстрационные. Реальная выдача NFT, Stars и TON/USDT-платежи пока не подключены.

## Платежи и правила
Цифровые товары и услуги внутри Telegram должны оплачиваться Telegram Stars (XTR). TON/USDT нельзя использовать как обход Stars для таких продаж. Отдельные on-chain операции с NFT требуют самостоятельной интеграции и проверки правил Telegram и законодательства.

В этом MVP розыгрыш бесплатный: платные случайные кейсы не реализованы. Платный случайный приз может подпадать под правила азартных игр/лотерей в зависимости от юрисдикции.

## Запуск
1. Нужен Python 3.11+.
2. Создайте бота через @BotFather.
3. Скопируйте `.env.example` в `.env`, заполните токен и HTTPS-адрес Mini App.
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите API: `uvicorn app:app --host 0.0.0.0 --port 8000`
6. Разместите API на HTTPS-хостинге.
7. Запустите бота: `python bot.py`

## Перед публичным запуском
Обязательно добавить серверную проверку Telegram `initData` (сейчас явно помечено DEMO), админскую авторизацию, реальную выдачу NFT через выбранную TON-коллекцию, резервное копирование, правила розыгрыша, политику конфиденциальности и аудит безопасности.
